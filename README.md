# Инфоген — генератор заданий ОГЭ по информатике

**[oge-infogen.ru](https://oge-infogen.ru)**

Бесплатный тренажёр для подготовки к ОГЭ по информатике. В отличие от сборников
с фиксированным набором задач — генерирует задания бесконечно, каждое с уникальным
сидом. Подходит как ученикам для самостоятельной подготовки, так и учителям для
составления работ.

## Режимы работы

### 🎯 Тренажёр
Выбор номера задания (1–16) и уровня сложности: *легче ОГЭ*, *как на ОГЭ*,
*сложнее ОГЭ*. Задания генерируются бесконечно — не фиксированная база, а новое
условие каждый раз. Есть подсказка по решению и разбор после ответа.
Автопроверка работает для всех заданий, включая задания второй части (№ 13–16).

### 📄 Вариант
Полноценный вариант из 16 заданий с выбором уровня сложности. Встроенный таймер,
режим без подсказок — как на реальном экзамене. После завершения: результаты
по каждому номеру, баллы, оценка, разборы решений.

### 📦 Набор (для учителей)
Создание большого пула заданий за один раз. Готовый набор можно распечатать
или скачать архивом. В архиве — файлы заданий и блокнот для ученика, куда он
вписывает ответы и фамилию. Затем учитель загружает заполненные блокноты обратно
в сайт — система автоматически проверяет ответы и выставляет балл каждому ученику.
