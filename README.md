# Инфоген — генератор заданий ОГЭ по информатике

**[oge-infogen.ru](https://oge-infogen.ru)**

Бесплатный тренажёр для подготовки к ОГЭ по информатике. В отличие от сборников
с фиксированным набором задач — генерирует задания бесконечно, каждое с уникальным
сидом. Подходит как ученикам для самостоятельной подготовки, так и учителям для
составления работ и ведения классов.

Пользоваться генератором можно без регистрации. Аккаунты нужны для классов,
домашних заданий, статистики и истории решений.

Главное отличие: **автоматически проверяются и задания второй части (№ 13–16)**,
которые на реальном экзамене оценивает эксперт. Ученик сразу видит балл
и разбор, а учителю не нужно проверять такие работы вручную.


## Режимы работы

### 🎯 Тренажёр
Выбор номера задания (1–16) и уровня сложности: *легче ОГЭ*, *как на ОГЭ*,
*сложнее ОГЭ*. Задания генерируются бесконечно — не фиксированная база, а новое
условие каждый раз. Есть подсказка по решению и разбор после ответа.
Автопроверка работает для всех заданий, включая задания второй части (№ 13–16).

### 📄 Вариант
Полноценный вариант из 16 заданий с выбором уровня сложности. Встроенный таймер,
режим без подсказок — как на реальном экзамене. После завершения: результаты
по каждому номеру, баллы, оценка, разборы решений. Вариант можно сохранить
в виде кода, открыть по коду и распечатать (в том числе в PDF).

### 📦 Набор (для учителей)
Создание пула заданий произвольного состава: номера, уровни сложности, количество
позиций. Набор восстанавливается по короткому коду. Готовый набор можно
распечатать (с ответами или без, с подробным разбором) или скачать архивом.
В архиве — файлы заданий и блокнот для ученика, куда он вписывает ответы
и фамилию. Затем учитель загружает заполненные блокноты обратно в сайт — система
автоматически проверяет ответы, в том числе по заданиям второй
части (№ 13–16), и выставляет балл каждому ученику.
Набор можно выдать классу как домашнюю или классную работу.

## Для учителей

После регистрации с ролью «Учитель» доступен личный кабинет.

- **Классы.** Создание классов, у каждого — код и ссылка для приглашения учеников.
- **Ученики.** Ученики вступают по коду или ссылке. Ученика без электронной почты
  можно создать самому: сайт сформирует логин и пароль для входа.
- **Задания.** Выдача набора классу как домашнего задания (со сроком сдачи
  и числом попыток) или как классной работы. Можно скрыть разборы до завершения.
- **Результаты.** Журнал выполнения по каждому заданию, разбор ответов
  учеников, статистика по номерам ОГЭ, аналитика класса, карточка ученика.
- **Выгрузка в Excel.** Данные класса, результаты задания и аналитика
  выгружаются в файлы `.xlsx`.
- **Проверка бумажных и файловых работ.** Загрузка блокнотов из архива набора
  и закрепление результата пробника за учеником.
- **Уведомления.** Колокольчик на сайте и письма: сразу при сдаче работы,
  ежедневная сводка в выбранное время или без писем.

## Для учеников

- **Вступление в класс** по 6-символьному коду на странице «Задания», по ссылке
  от учителя или при регистрации.
- **Задания класса** со сроками, числом попыток и статусами; запуск работы
  и просмотр разбора после завершения.
- **Статистика** по каждому из 16 номеров ОГЭ.
- **История** всех решений: тренажёр, варианты, домашние и классные работы,
  пробники.
- **Уведомления** о новых заданиях и напоминание за сутки до срока сдачи.
